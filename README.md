# ABO グループ成長シミュレーター ver1.0.0

2026年11月6日 初期リリース。現在の画面・計算・操作を初期仕様として定義します。

## 初期仕様

### 成長モデル
- 「N人スポンサリング」：各人が設定した間隔後に1回だけN人をスポンサリングし、次の段へ広がるモデル。
- 「毎月スポンサリング」：本人を含む全員が参加翌月から毎月N人をスポンサリングし続けるモデル。製品購入は参加当月から継続する仮定。
- 毎月モデルの総人数は `(1+N)^経過月数`。N=1なら現在1人、1か月後2人、2か月後4人。12か月後は全体4,096人、本人の直下12人、最初のフロントの直下11人。
- 現在（0か月）は本人のみ。100万人を超える月は人数・月次金額の計算上限として扱います。

### 入力と操作
- 平均月間PV：初期値1万PV。
- ②フロント人数：1〜30人の選択式、初期値3人。
- 段階の間隔：初期値1か月。毎月モデルではこの入力を非表示にし、段階モデルへ戻すと入力値を保持。
- 予測期間：12／18／24／36か月、初期値12か月。
- 成績別ボーナスの参考換算比率：初期値・リセット値1.446（税抜BVの平均値）。
- タブ切り替えはページ再読み込みなし。入力・チェック状態・選択中の月を保持して再計算。
- 新しくリンクを開いたとき、再読み込み時、初期値に戻すボタン押下時に入力を初期化。端末へ入力を保存しません。
- スマホではタブが画面上部に追従。ヘッダーとタブはコンパクトな表示。

### 結果とボーナス
- 人数、グループPV、成績別ボーナス、追加ボーナスの内訳、推移グラフ、月ごとの一覧を表示。
- 直下系列へ分配する分を差し引いた本人の成績別ボーナス概算を表示。「直下フロント分を分配」と表記。
- 追加ボーナスはBSI（本人のリピート・オーダーを含む）、ブロンズ9、ブロンズ15、6％リーダーシップの4項目。初期状態はすべてON。
- SP以上の追加インセンティブ（月次Q・年次Q・年次フロントQ・達成一時金）は画面・合計・CSVの対象外。
- 毎月モデルでは各フロントの参加月、直下人数、系列全体人数を確認可能。
- モバイルの一覧では人数・PVを短縮表示。ボーナスは全額を表示し、必要に応じて折り返して横へのはみ出しを防止。
- UTF-8 BOM付き月別CSVを保存可能。

## 計算の前提

全員が同じPVを毎月購入し、指定人数をスポンサリングする理想化した仮定です。離脱・購入停止・返品・個別の受給履歴・正式資格認定は再現しません。

BSIは本人と対象者が各1万PV以上、対象者の登録月を含む13か月以内を仮定。リピートは本人が現在新規登録し初月から1万PVを継続する仮定で、3／6／9／12連続月に1,000／2,000／3,000／6,000円を試算します。系列下位のリピート受給額を本人には加算しません。

ブロンズ9・15は直下系列・PVと受給期間・回数の簡易条件を使用し、過去の受給歴などは仮定です。リーダーシップは有資格SPの実績条件・最低保証調整の概算で、独自に税抜BV平均1.446と10％相当を使用します。詳細設定の換算比率は成績別ボーナスに適用します。

非公式の教育用試算で、実際の収入や認定を保証しません。小売利益・経費・税金は含めません。制度資料は「ビジネスサポート2027」と「概要書面2026年9月版」をベースとします。概要書面PDF本体の再照合は未完了です。

## ファイル・実行

- `index.html`：段階モデルを初期選択する入口。
- `continuous.html`：毎月モデルを初期選択する入口。両入口でタブ切り替え可能。
- `incentives.js`：共通の計算補助。
- `test.cjs`：計算境界、人数上限、1〜30人の選択、タブ切り替え・入力保持のテスト。

同じフォルダに置いてブラウザで開けます。テストはNode.jsで `node test.cjs`。

Cloudflare Pagesはmainから自動公開し、ビルド不要、出力先はリポジトリ直下です。`_headers`でHTMLのキャッシュを抑制します。

公開先：https://abo-growth-simulator.pages.dev/
