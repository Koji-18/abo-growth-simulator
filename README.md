# ABO グループ成長シミュレーター v1.8（非公式）

静的HTML。`index.html` と `continuous.html`、`incentives.js` を同じ場所に配置して開きます。通信・保存不要です。

## 2つのモデル

|ページ|紹介の前提|N=1の累計人数（0〜3月）|
|---|---|---|
|index.html|各人が設定間隔後に1回だけN人紹介|1,2,3,4|
|continuous.html|本人を含む既存全員が毎月N人追加、新規者は翌月から紹介|1,2,4,8|

継続モデルは総人数 `(1+N)^月数`。本人の直下系列は毎月N本増え、参加月ごとに系列PVを計算します。各系列の合計と本人PVを使い、二重計上を避けます。購入・紹介の継続、離脱なしという仮定です。100万人超は算出停止。段階モデルの間隔入力は継続モデルでは使用しません。

## 追加インセンティブ

チェックはBSI、ブロンズ9、ブロンズ15、6％リーダーシップ、SP以上の追加インセンティブの5つ。全ON、平均1万PV、N=3、期間12月、現在0月からの初期値を維持します。

- BSI：当月本人・対象者各1万PV、登録月を含む13月以内。継続モデルでは直下の登録月ごとに13月の対象期間を判定します。
- BSI内のリピート：本人が現在新規ABO登録し、初月から毎月1万PVの仮定。3/6/9/12連続月で1,000/2,000/3,000/6,000円。系列下位の受給額を本人に足しません。2026年9月以降の新規・切替が対象。関数は3月以内の初達成、途中未達による停止、登録初月達成→翌月未達→翌々月再達成の例外も扱います。画面では一定PVの仮定のみ。
- SP追加：折り畳み条件入力による独立試算。未確認は `null` / 算出不能。前年度未入力をゼロとみなしません。仮定選択をしても資格の証明にはなりません。
- 月次Q：本人月1万PV、有資格SPⅠ10万円、Ⅱ2万円、Ⅲ対象外。
- 年次Q：PT以上、年度内Ⅰ・Ⅱ6月以上、本人年間12万PV以上。前年度Ⅰ・Ⅱ月数との増加・維持・減少テーブル。12月維持60万円、増加75万円。
- 年次フロントQ：FPT以上、年度12Qまたは10Q以上＋総2160万PV/アワード1800万PVのいずれか、本人年12万PV以上。直下Q10/Q11＋PV条件の12月補正をした21％系列月数を手入力。前年度も同じ補正基準が必要。
- 一時金：GP148,000円、PT296,000円、FPT517,000円。正式新認定または新認定翌年度の同資格初回再認定の条件を満たす仮定と年度入力が必要。翌々年度以後の再認定を受給対象にしません。

会計年度は9月〜翌8月、年度番号は終了年（例2027年度＝2026年9月〜2027年8月）。年次Q2種の支払いは年度終了後10月末。月次Q/BSIは月次。一時金の正確な支払月は確認できず算出不能。別試算を人数モデルの各月へ自動加算しません。CSVの別試算は入力した年度・認定1件の値を参考列として各行に反復します。**合算しないでください**。

v1.7のGP後にSPⅠを自動継続し一時金を認定月へ加算する予測は、認定履歴・支払月を確定できないため条件入力へ変更しました。GP新認定は12月以内3Q、PT新認定は12月以内6Q（3月連続含む）。再認定GPは会計年度3Q、PTは6Q（連続不要）。FPTは年度12Qほか代替PVルートあり。正式資格判定を人数だけでは行いません。

## 制約・資料

新規追加制度は添付公式『ビジネスサポート2027』冊子10〜11、16〜21頁を原文確認。既存成績別ボーナスはv1.7の概要書面2026年9月版ベースの計算を継承。概要書面PDF本体はこの作業環境にはないため再照合できていません。将来年度も同制度が続くという仮定です。

平均PV:税込BV相当1:1.59。実際の商品別BV・税率・個別資格、過去受給履歴は再現しません。ブロンズ9/15、リーダーシップは従来同様の仮定付き概算。小売利益・経費・税金は含みません。公式ツール・収入保証ではありません。
