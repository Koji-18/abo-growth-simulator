# ABO グループ成長シミュレーター v1.9

- index.html：各人が1回だけ指定人数を紹介する段階モデル。
- continuous.html（公開URL /continuous）：全員が参加翌月から毎月N人を紹介し続ける継続モデル。
- Nは「各人が毎月追加紹介する人数」で0〜12人に変更可能。現在は本人1人。累計人数は(1+N)^月数。N=1なら1→2→4→8人、N=2なら1→3→9→27人。
- N=1の12か月後は本人の直下12人、最初のフロントの直下11人、グループ全体4,096人。各フロントの詳細に参加月・直下人数・系列全体人数を表示。
- SP以上の追加インセンティブのチェック・入力・結果・CSV列を削除。追加ボーナスはBSI（本人リピート含む）・ブロンズ9・ブロンズ15・6％リーダーシップの4項目。
- 平均PV・人数・予測期間などの初期値は従来どおり。100万人上限、CSV、モバイル対応を維持。

静的HTMLとincentives.jsを同じ場所へ配置。Cloudflare Pagesはmainから自動公開。テストは `node test.cjs`。

全員の購入・紹介継続、離脱なしの仮定。追加ボーナスは個別履歴や正式資格を確定しない概算。公式の収入保証ではありません。新規制度はビジネスサポート2027、既存成績別計算はv1.7の概要書面2026年9月版ベースを継承しています。
